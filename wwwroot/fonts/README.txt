FILSON SOFT FONT SETUP

This project is configured to use Filson Soft, but the licensed font files are not included.

For the standalone index.html preview, place your licensed files here:
  fonts/FilsonSoft-Regular.woff2
  fonts/FilsonSoft-Medium.woff2
  fonts/FilsonSoft-Bold.woff2

For ASP.NET MVC, place the same files in:
  wwwroot/fonts/FilsonSoft-Regular.woff2
  wwwroot/fonts/FilsonSoft-Medium.woff2
  wwwroot/fonts/FilsonSoft-Bold.woff2

If Filson Soft is installed on your computer, the browser may use the local installed version via the font-family fallback.
