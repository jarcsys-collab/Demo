# Middle Mobile Login

This version is **mobile-only**.

- Open `index.html` directly in a browser to preview it.
- On desktop, the mobile canvas stays at a maximum width of 430px and is centered on screen.
- `Views/Account/Login.cshtml` is the ASP.NET MVC/Razor version.
- `wwwroot/images/middle-logo.png` is the supplied Middle logo, rendered white with CSS.
- The UI is configured for **Filson Soft**.

## Filson Soft

The font itself is not bundled. Add your licensed `.woff2` files using these names:

- `FilsonSoft-Regular.woff2`
- `FilsonSoft-Medium.woff2`
- `FilsonSoft-Bold.woff2`

For the HTML preview, put them in `/fonts/`.
For MVC, put them in `/wwwroot/fonts/`.
